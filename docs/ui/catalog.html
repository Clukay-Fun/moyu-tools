动效

下面每张卡片都在自动循环播放应用里的真实动效（用的是应用本身的类名和过渡，不是另画的动画）。动效只服务于反馈：按下有回弹、浮层有出现、状态切换有滑动。时长与缓动一律取变量。

时长
按用途命名，同用途才共用：--dur-hover 悬停的颜色/背景/边框 · --dur-press 按下与开关 · --dur-popover 浮层入场 · --dur-popover-exit 浮层退场 · --dur-panel 面板（轻提示、图片编辑面板）。取值不同的旧写法（进度条 160ms、拖放高亮 150ms 等）保持原值，不为统一改变节奏
缓动
--ease-out——出现和位移；颜色、背景这类非位移变化用 ease；两个位置之间来回滑（分段指示器）现在用的是 cubic-bezier(0.77, 0, 0.175, 1)，还没有变量
动效总开关
目前关闭：主窗口、截图、钉图的 <body> 都带 data-motion="off"，所有过渡、动画、按下缩放和 JS 进场动画都不做，状态直接切换（styles/15-a11y.css「动效总开关」、main.js motionDisabled）。恢复：删掉这个属性。下面各项是打开时的规格
减弱动效
系统开启「减少动态效果」时，全局兜底只保留颜色/透明度过渡，位移、缩放、按下回弹一律不动（styles/15-a11y.css「减弱动效兜底」）

按下回弹

scale(var(--press-scale))（0.97）· --dur-press · --ease-out

错误态
统一加 aria-invalid="true"（不要再切 .invalid 之类的类名）：红框 + 淡红外圈，悬停和聚焦时保持；禁用时不显示。步进器的错误画在外框上。错误提示文字用 aria-describedby 关联到输入框，读屏会念出原因。只有输入内容本身不合法才标 aria-invalid；保存、复制、联动这类操作失败只在提示区显示错误，不动输入框

库存 / 定制

库存与定制（原 ajuan-erp）是 React + CSS Modules，组件在 src/renderer/erp/components/ui，这里只记约定，不放静态示例；看实际效果请进应用的「库存」「定制」。

变量
组件只用 --erp-*，在 src/renderer/erp/styles/erp.css 映射到摸鱼变量（文字 --foreground / --muted / --faint、描边 --hairline / --border-neutral、强调色 --accent、圆角 --r-sm / --r-md / --radius、阴影 --shadow-small / --shadow-panel）。不要在组件里直接写摸鱼变量，也不要定义无前缀的同名变量（--accent、--danger、--z-popover 曾经撞名）。
外观对齐
通用组件的外观直接取摸鱼的组件语义变量（01-tokens.css）：Button / IconButton ↔ --btn-*（同 m-btn），SegmentedControl ↔ --seg-*，Input / Select 触发器 ↔ --field-*，Select / Menu 弹层 ↔ --menu-*，ConfirmDialog / Drawer ↔ --dialog-* 与 --backdrop，Card / Panel ↔ --card-*。尺寸保持库存的紧凑档（28 / 32）。改这些外观改摸鱼的变量即可，两边一起变

入库蓝、出库琥珀、调整青、期初灰蓝、告急红是业务含义，固定取值、不随强调色变化；浅色 / 深色各一套。
弹层
抽屉、对话框、下拉由 Base UI portal 到 body（[data-base-ui-portal]），层级 --erp-z-* 排在摸鱼弹层之上。

使用约定

颜色、字号、圆角、间距从变量取；需要新值时先加变量，再在这里补示例。

浅色模式下 --border / --control-border 是白色半透明，放在浅底上几乎看不见——需要可见描边时用 --border-neutral（悬停 --border-neutral-hover）；按钮不走这条，见上方「按钮外观」。

键盘焦点统一为「实线内圈 + 柔光」（--focus-ring-color / --focus-glow），只在 Tab 操作时出现；焦点样式里不要改 border-radius，outline 与 box-shadow 本身会跟随控件圆角；新增的可交互控件如果真实的 input 被隐藏了，要把焦点环画到可见的替身上（参考开关）。

目录建成时顺手修掉的：深色模式下 .gbtn.primary 丢失主题色填充（一条多余的 [data-theme="dark"] .gbtn 规则特异性更高）；开关禁用态与可用态看不出区别。

刀模画布、图片编辑器、截图覆盖层有各自的交互约束，不为了统一去改它们已验收的样式。

盘点现状：node scripts/style-report.mjs（加 --json 输出机器可读结果）。

门槛：npm run lint:css——Stylelint 禁止 components/ 里写死颜色、圆角、字号；样式报告和 scripts/style-baseline.json 比，写死的值、重复选择器、废弃类名、没人用的变量只能减不能加。
